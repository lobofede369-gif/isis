Configuración

Tus claves viven solo en este navegador (localStorage). Nunca se guardan en el servidor ni en ningún archivo.

La clave de FableAI se crea en el panel de FableAI (API Keys). La clave de API de n8n se crea en n8n → Settings → n8n API. El token de WhatsApp se consigue en Meta for Developers → tu app «PCN Bot» → WhatsApp → API Setup → Token de acceso. La clave de TextBee y el ID del dispositivo se consiguen en textbee.dev: crea una cuenta, instala la app en tu teléfono, agrega el dispositivo escaneando el QR y crea una API key. Sin el ID, Isis usa tu dispositivo por defecto. El Client ID y el Client Secret de Spotify se consiguen en developer.spotify.com/dashboard: crea una app (Create app), en Redirect URIs pon la dirección de Isis (la misma que ves en el navegador) y copia los dos datos aquí. Spotify exige cuenta Premium para que Isis controle la reproducción.
